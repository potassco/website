anthem-cx automatically finds counterexamples to the external equivalence of two ASP programs.
Given two logic programs and a user guide declaring their input and output predicates,
it searches for an input on which the two programs exhibit different external behavior.
If such an input exists, it is reported as a counterexample;
this complements the verification of external equivalence with [anthem](https://potassco.org/anthem/).
